.lock 文件通常是锁文件（lock file），用于防止多个进程同时操作同一个资源。

常见用途：

1. 防止多个程序同时运行

例如：

/var/run/myapp.lock

程序启动时：

检查 lock 文件是否存在
存在 → 说明已有实例在运行，退出
不存在 → 创建 lock 文件，继续运行


文件太长时，只保留开头 + 结尾，中间砍掉，并插一句“这里被截断了”的提示。如：“这个文件太长了，我只保留了开头和结尾，中间省略了，你要完整内容请用工具读文件”
